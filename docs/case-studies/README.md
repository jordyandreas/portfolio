## Video Call Platform Frontend

| File | Use |
| --- | --- |
| `video-call-platform-frontend.md` | Source markdown (editable) |
| `video-call-platform-frontend.print.html` | Print-ready HTML with rendered Mermaid diagrams |

### Export to PDF (recommended)

1. Open `video-call-platform-frontend.print.html` in Chrome (double-click or drag into the browser).
2. Wait until all three diagrams finish rendering.
3. **File → Print…** (or `⌘P`).
4. Destination: **Save as PDF**.
5. Suggested filename: `Jordy-Andreas-Case-Study-Video-Call-Platform.pdf`.
6. Upload that PDF to the application form.

Tip: In the print dialog, enable **Background graphics** so borders and the note callout print cleanly.
